# 留白

横屏看 4:3 视频时，把屏幕左右两侧的黑边盖成白色（悬浮窗遮罩，不修改视频本身）。

## 下载
最新安装包：https://github.com/nlhaiuy/Liubai/releases/latest/download/Liubai.apk
（所有版本见 [Releases](https://github.com/nlhaiuy/Liubai/releases)。）

## 构建
- Android Studio 直接打开本目录，Run 即可；或命令行 `gradle assembleDebug`（需要 JDK 17 + Android SDK）。
- 没有环境：把本目录推到 GitHub，Actions 会自动构建，在 Artifacts 里下载 `app-debug.apk`。

## 使用
1. 打开 App，点底部“开启遮罩”，按提示授予“显示在其他应用上层”权限。
2. 回到视频 App 横屏播放；遮罩宽度 = (屏幕宽 − 屏幕高×比例) / 2。
3. 不贴合时用“宽度微调”：滑条或加减按钮；滑条下面会显示带单位的微调值（dp）和此刻单侧白边的实际宽度。
4. 竖屏时自动不显示。
5. “生效范围”选“白名单”时，只在你勾选的视频软件里自动显示，需要开启无障碍（点提示条会直接跳到留白的无障碍页）；选“全局”则开启后到处显示。
6. “显示时机”选“仅播放时”，只有检测到有声播放才显示，暂停后保留 30 秒；静音播放的视频不会触发。
7. 右上角状态：已关闭 / 待命中（下面一行说明在等什么）/ 生效中。

## 实现要点
- 白名单模式下遮罩由无障碍服务直接挂载（TYPE_ACCESSIBILITY_OVERLAY）：不需要悬浮窗权限、不需要常驻通知。全局模式且没开无障碍时，才回退到悬浮窗 + 前台服务（通知可点击回到设置，带“关闭”按钮）。
- 开机 / 应用更新后，全局模式的遮罩会自动恢复。
- 离开白名单软件后遮罩延迟约 0.4 秒再撤，分享面板、权限弹窗等短暂窗口不会让它闪。

## 说明
- 包名 `com.liubai.app`。从旧版（白边）升级需要先卸载旧版，两者是不同的应用。
